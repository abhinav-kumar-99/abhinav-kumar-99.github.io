# Project Overview

This repository is Abhinav Kumar's personal website, built with Jekyll and the al-folio theme.

Last updated: 2026-08-17

Related: [Wiki index](index.md), [GitHub Pages deployment](workflows/github-pages.md), [Repository README summary](sources/summaries/readme.md)

## Evidence

- `_config.yml` identifies the site URL as `https://abhinav-kumar-99.github.io` and describes the site as powered by Jekyll and al-folio.
- `Gemfile` defines the Jekyll and plugin dependencies.
- `.github/workflows/jekyll.yml` builds and deploys the generated `_site` directory to GitHub Pages.

## Source Layout

- Content: `_pages/`, `_posts/`, `_projects/`, and `_news/`.
- Theme and presentation: `_layouts/`, `_includes/`, `_sass/`, and `assets/`.
- Configuration and dependencies: `_config.yml` and `Gemfile`.
